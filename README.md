# Benta Enchanted Escapes

Esta hospedagem mais de 200 mil seguidores no Instagram (https://www.instagram.com/bentarosaurubici ) e este é o site atual deles, https://www.bentarosaurubici.com.br/

Ainda não olhei o Google mas vi o potencial do local e , ao simular uma reserva, notei que praticamente todo o mês de outubro está disponível, ou seja, eles precisam atrair mais clientes! (detalhe, um final de semana pra um casal ficou em R$3.900,00!)

Pensando nisto, quero que você faça um site premium usando todas as informações e imagens contidas no site oficial e no Insta deles.
Mantenha a simulação de reserva e eles tem um modelo de chat que funciona 24hs, depois adaptamos isto.

Inicialmente, quero que crie somente a Home (mas deixando tudo preparado pra finalizar o site caso eu consiga vendê-lo) pra que eu possa surpreender o proprietário!

Entregue o seu melhor e deixe tudo com menos cara de IA possível!
